# Лабораторная работа №2: Линейные модели для регрессии

Данный репозиторий содержит скрипт на Python для выполнения второй лабораторной работы. Программа демонстрирует работу линейных моделей регрессии, эффект регуляризации (L1 и L2) и визуализирует их коэффициенты.

## 📋 Требования к системе]

- ОС: Windows (для `start.bat`).
- Python 3.10 или выше.
- Интернет для первичной установки библиотек.

## 📦 Используемые библиотеки

Все зависимости указаны в `requirements.txt`:

- `numpy` — математические операции
- `scikit-learn` — генерация датасета, модели `LinearRegression`, `Ridge`, `Lasso`
- `matplotlib` — построение графиков

## 🚀 Как запустить

### Способ 1: Автоматический (Рекомендуемый)

1. Дважды кликните по файлу `start.bat`.
2. Скрипт сам создаст виртуальное окружение (`.venv`), установит нужные библиотеки и запустит `lab2.py`.
3. Результаты (графики) появятся в папке `lab2_results`.

### Способ 2: Ручной (через терминал)

1. Откройте терминал в папке с проектом.
